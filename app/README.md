# Holt App

This is the desktop application shell for Holt.

The app combines a Svelte frontend with a Rust/Tauri backend. During the public
cut, prefer the root README and `docs/PUBLIC_CUT_AUDIT.md` for current status.

## Common Commands

- `npm install`
- `npm run check`
- `npm run build:sidecar`
- `npm run tauri dev`
